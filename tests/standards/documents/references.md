Справка `docs/` для агента — правило Claude Code с `paths:` во frontmatter: `install -g` ставит её в правила машины
(`~/.claude/rules/elves-<имя>.md`, capability `elves#install`), и Claude Code грузит её сам, когда агент читает или правит
подходящий файл — тесты, workflow, compose. Справки «агент читает по необходимости» нет.

Почему (#846): за 1–16 ноября справки `docs/` прочитаны 12 раз на 69 сессий и 1 406 субагентов, за 30 дней до 17 ноября
по отчёту `est usage` — `testing.md` 37 раз, остальные — от 0 до 7. Ссылка из канона не доводила агента до справки, а
`paths:` доводит без ссылки: правило приходит вместе с файлом, ради которого оно написано. Справки без чтений ушли:
`judgment.md` — суждения короткими пунктами в раздел «Judgment» канона, `production.md` — туда же, `pr-checks.md` —
в `reference.md` скилла `ci-wait`, у механизма ожидания.

Без `paths:` в `docs/` остаются документы для человека — они вне правила с причиной в тесте: установка (README ведёт
на неё), инструкция для агента не Claude Code (#848) и шаг владельца с кэшем промпта. Это и есть строка «оставить,
потому что …» для кандидатов `est usage`: отчёт видит чтения агента, а читает их человек.

Отвергнуто: держать справки в `reference.md` скиллов — их тоже читают по указателю, а не по файлу; копия справки в
`.claude/rules` проекта — тонкий проект не хранит флоу (#552), и правило с машины грузится без диалога внешних импортов.
