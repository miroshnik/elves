Обход команды флоу — `gh`-вызов, который флоу делает своей командой, — останавливает хук `PreToolUse` Claude Code
(`github hook guard`, #839): вызов запрещён, а в причине — готовая команда флоу, которую модель зовёт вторым вызовом.

Правила «`task show`, а не `gh issue view`» и «ждать через `ci-wait`» были прозой канона и соблюдались наполовину: за
1–16 ноября `gh issue view` — 644 вызова против 588 `task show`, `gh run watch` — 102. Проза стоит токенов в каждой
сессии и не держит ничего; хук `PreToolUse` умеет запретить вызов с причиной для модели (`permissionDecision: "deny"`,
`permissionDecisionReason`) и действует в субагентах. Поэтому правило — механизм, а фразы о нём из `AGENTS.md` и
`SKILL.md` ушли.

Список обходов — данные одного файла, `skills/github/scripts/bypasses.ts`: правило (`Bash(gh issue view *)` —
синтаксис разрешений Claude Code), флаги, без которых вызов не обход (`gh issue edit` без `--body` — метка, а не
описание), флаги, с которыми вызов — чтение, которого у команд флоу нет (`--json`, `--web`), замена и причина. Новое
правило — строка в нём и её случаи в таблице теста: правило без случая запрета и случая пропуска — красный тест.
`install -g` ставит по обработчику на правило: `if` Claude Code берёт одно правило и запускает хук только на вызов с
подходящей подкомандой, остальные вызовы процесса не стоят; сам хук сверяет те же слова команды — Claude Code без `if`
запускает его на каждый вызов, и решает всё равно хук.

Свой репозиторий — репозиторий сессии: `origin` каталога из входа хука. Вызов о другом — `--repo`, `GH_REPO`, URL
issue, `cd` в другой чекаут — не обход: команды флоу — для задач репозитория сессии, а `task show` в каталоге сессии
показал бы чужой задаче номер своей. Каталог без `origin` на GitHub — задач флоу нет, обходов тоже. Составная команда
разбирается, как её разбирает `if`: подкоманды через `&&`, `|`, `;`, внутри `$(…)` и обратных кавычек, в двойных
кавычках тоже; текст heredoc, в одинарных кавычках и комментарий — не команды, и тело PR со словами `gh issue view` не
запрещено.

Хук отвечает за десятки миллисекунд — без сети, один `git remote get-url` на каталог, — и его своя ошибка (вход не
JSON, git нет, таймаут) пропускает вызов: код 0 и пустой вывод — для Claude Code «решения нет». Флоу не останавливает
работу из-за себя.

Отвергнуто (вопрос 1 задачи): переписывать команду (`updatedInput`) — модель получила бы вывод команды, которой не
звала, и не узнала бы о замене; запрет стоит один ход и учит. Хук на каждый Bash-вызов без `if` — процесс bun на
каждую команду сессии. Код 2 со stderr вместо JSON — тот же запрет, но без формы, которую Claude Code описывает для
решения `PreToolUse`.
